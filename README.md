# 🎂 Cake-Dash

A fun cake-running endless runner game! 🏃‍♀️🍰

## 🎮 About

Cake-Dash is a simple endless runner game where you control a character,
avoid kitchen obstacles, and try to achieve the highest score.

## ✨ Features

🎮 Endless runner gameplay
🍰 Cake-themed design
🧁 Running cake character
🧑‍🍳 Cake-making kitchen obstacles
📱 Keyboard and touch controls
🏆 Score tracking
🎨 Fun and colorful interface

## 🛠️ Technologies

- HTML
- CSS
- TypeScript
- Vite
